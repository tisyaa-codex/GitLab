

\# Frequently Asked Questions (FAQ)



\## 1. What is Git?



Git is a version control system used to track changes in files.



\## 2. What is GitHub?



GitHub is an online platform used to host Git repositories.



\## 3. What is GitHub Pages?



GitHub Pages is a service used to publish static websites directly from GitHub repositories.



\## 4. What is a Git commit?



A commit records changes made to files in a Git repository.



\## 5. How do I check Git status?



Use the command:



```bash

git status

```
