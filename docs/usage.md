

\# Usage Guide



\## 1. Check Git Installation



```bash

git --version

```



\## 2. Configure Git



```bash

git config --global user.name "Tisya"

git config --global user.email "your-email"

```



\## 3. Initialize Repository



```bash

git init

```



\## 4. Add Files



```bash

git add .

```



\## 5. Commit Changes



```bash

git commit -m "Initial commit"

```



\## 6. View Commit History



```bash

git log --oneline

```
